Cloud Projects

Manage saved stakeholder requests and refine them into backlog items. This cloud workflow is separate from the fictional Guided Simulation; it does not run real AI or update the simulation lifecycle.

Connect your Supabase project

Enter the project URL and public publishable/anon key from Supabase Project Settings → API. Never enter a service-role key, secret key, or database password.

Sign in or create an account

RLS must be configured so each authenticated user can access only their own records.

If email confirmation is enabled, confirm Supabase’s email before signing in. Use a unique password.
